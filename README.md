# 📄 Inscription
# Sur une seule VM 
## Installer git 
```
sudo apt-get install git
```
## Récupérez le projet github
```
git pull https://github.com/Losange2/Inscription-BTS-public
```
## Puis faites ça sur le fichier pour mettre les droits sur les scripts d'installation
```
sudo chmod +x installationdb.sh
sudo chmod +x installationprojet.sh
```
## Puis lancer les scripts
```
.\installationdb.sh
.\installationprojet.sh
```
